# AI Project Rules

This file contains project-specific AI rules for the Utils library.

## Project Overview

This is a TypeScript utility library providing unit conversion utilities
(`BitUnit`, `ByteUnit`).

## Technology Stack

- Language: TypeScript
- Build Tool: npm with tsup
- Testing: Vitest

## Project-Specific Guidelines

- Follow existing code conventions in the project.
- Keep the exported API small and stable.
- Write unit tests for new functionality.
